# 01 — Terminal and environment

A terminal is a text interface to your development environment. A folder is a place in the filesystem; the current folder determines where commands act.

1. Run pwd to show your current folder.
2. Run ls to list files.
3. Run cd msc-developer-workspace to enter your cloned fork.
4. Run code . to open the current folder in VS Code.
5. Find starter/index.html and starter/styles.css.

On Windows with WSL, the VS Code window can run on Windows while Git, project files, and the terminal run in Linux. WSL is optional for this exercise.

Checkpoint: you can point to the folder containing README.md and say which terminal environment you are using. See [terminal cheatsheet](../cheatsheets/terminal.md).
