# Git cheatsheet

| Command | Meaning |
| --- | --- |
| git status | Show changed files and current branch |
| git diff | Inspect unstaged changes |
| git add starter/ | Select portfolio files for the next commit |
| git diff --cached | Inspect staged changes |
| git commit -m "Message" | Save a checkpoint |
| git push | Send commits to your fork |

Git is your local history. GitHub hosts a copy of the repository online. Review the diff and the actual page before committing.
