# VS Code cheatsheet

| Action | Windows/Linux | macOS | Menu alternative |
| --- | --- | --- | --- |
| Save | Ctrl+S | Cmd+S | File → Save |
| Find | Ctrl+F | Cmd+F | Edit → Find |
| Command Palette | Ctrl+Shift+P | Cmd+Shift+P | View → Command Palette |
| Explorer | Ctrl+Shift+E | Cmd+Shift+E | View → Explorer |
| Source Control | Ctrl+Shift+G | Ctrl+Shift+G | View → Source Control |
| Terminal | Use menu | Use menu | Terminal → New Terminal |
| Open folder | Use menu | Use menu | File → Open Folder |

Custom bindings/layouts differ; menus are fallback. Search Palette for word wrap, zoom or WSL connection actions.

**WSL:** remote status = Ubuntu/WSL; Explorer and terminal pwd refer to one Linux checkout.

**Develop:** edit starter/ → save → refresh browser → resize/test.

**Source Control:** inspect Changes → + stage → inspect Staged Changes → message/Commit → …/Push. Git must be installed in the workspace environment. − unstages; Discard Changes can remove edits. Sync may pull and push; first use Push deliberately.

CLI is useful for remote/history inspection and more explicit operations. It is not a separate history system.
