# Official learning resources

Start with [Repeat the demo](guides/repeat-the-demo.md), then use the official references below for deeper learning.

Follow [learning path](README.md#your-learning-path) first. These are references, not required reading before starting.

## WSL → terminal

- [Microsoft WSL installation](https://learn.microsoft.com/en-us/windows/wsl/install): supported Windows setup and restart.
- [WSL basic commands](https://learn.microsoft.com/en-us/windows/wsl/basic-commands): distro selection/management.
- [WSL environment/file storage](https://learn.microsoft.com/en-us/windows/wsl/setup/environment): Linux projects with Windows apps.
- [VS Code in WSL](https://code.visualstudio.com/docs/remote/wsl): Windows editor connected to Ubuntu tools/files.

## GitHub → Git

- [GitHub signup](https://github.com/signup): create your account.
- [Fork a repository](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo): make/clone your copy.
- [Git installation](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git): install in project environment.
- [First-time Git setup](https://git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup): commit identity.
- [About version control](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control): why record history.
- [Recording changes](https://git-scm.com/book/en/v2/Git-Basics-Recording-Changes-to-the-Repository): staging, diffs and commits.
- [Working with remotes](https://git-scm.com/book/en/v2/Git-Basics-Working-with-Remotes): fetch/pull/push.
- [GitHub credential helpers](https://docs.github.com/en/get-started/git-basics/caching-your-github-credentials-in-git): OS-specific browser sign-in.
- [Personal access tokens](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens): terminal-auth alternative.

## VS Code → development / Source Control

- [Download](https://code.visualstudio.com/download) and [first steps](https://code.visualstudio.com/docs/getstarted/overview).
- Installation: [Windows](https://code.visualstudio.com/docs/setup/windows), [macOS](https://code.visualstudio.com/docs/setup/mac), [Linux](https://code.visualstudio.com/docs/setup/linux).
- [Command-line launcher](https://code.visualstudio.com/docs/configure/command-line): code . troubleshooting.
- [Version control in VS Code](https://code.visualstudio.com/docs/sourcecontrol/overview): Git UI, staging and commits.
- [MDN HTML content](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content).
- [MDN CSS styling](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content).
- [W3C accessibility principles](https://www.w3.org/WAI/fundamentals/accessibility-principles/): readable/keyboard-friendly output.
